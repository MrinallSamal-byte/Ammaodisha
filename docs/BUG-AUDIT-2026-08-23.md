## Medium / Low — recommended next (not yet fixed)

2. 🔜 Upload XHR lacks timeout/cancel (`backend.ts:714-769`) — stalled connections lock modals in saving state forever.
3. 🔜 Realtime ping refetches can resolve out-of-order (`App.tsx:57-67`) — add request token.
